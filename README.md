# Movie Recommendation System
A simple Movie Recommendation System built using Python that recommends movies based on genres and user ratings.

## Features
- Content-Based Filtering
- Collaborative Filtering
- Movie Similarity Recommendations
- User-Based Recommendations

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NumPy

## Installation

1. Clone the repository:
   git clone https://github.com/surya676/movie-recommendation-system.git

2. Install dependencies:
   pip install pandas scikit-learn numpy

3. Run the project:
   python movie_recommender.py
